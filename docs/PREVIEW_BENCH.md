# 미리보기 전송 실측 (0단계)

시계에서 폰 카메라 미리보기를 보려면 폰이 흑백 저해상도 프레임을 블루투스로 계속 보내야 합니다.
이 측정은 카메라를 붙이기 전에 **그 경로가 얼마나 빠른지**만 잽니다. 결과에 따라 미리보기를 만들지,
"촬영 직후 정지 화면 1장"으로 범위를 줄일지 정합니다.

## 무엇이 들어 있나

| 구성 | 역할 |
|---|---|
| `garmin_bench/` (CamBench) | 측정 전용 시계 앱. 기존 CamRemote 위젯과 앱 ID가 달라 서로 영향이 없습니다 |
| `BenchSender.kt` | 동반 앱 안의 테스트 프레임 송신기. 시계가 요청한 크기의 가짜 흑백 프레임을 하나씩 보냅니다 |

시계는 4가지 크기를 각각 20초씩, 총 80초 동안 받습니다.

| 순서 | 크기 | 회색 단계 | 프레임 1장 전송량 |
|---|---|---|---|
| 1 | 64×64 | 4단계(2bit) | 약 1.3KB |
| 2 | 80×80 | 4단계(2bit) | 약 2.1KB |
| 3 | 80×80 | 16단계(4bit) | 약 4.3KB |
| 4 | 100×100 | 16단계(4bit) | 약 6.7KB |

## 빌드

시계 앱은 기존 위젯과 같은 방법으로 빌드합니다. Connect IQ SDK Manager에서 **Forerunner 165 기기 파일**을 받아 둬야 합니다.

```bash
monkeyc -d fr165 -f garmin_bench/monkey.jungle -o garmin_bench/bin/CamBench.prg -y developer_key.der
cp garmin_bench/bin/CamBench.prg /Volumes/GARMIN/GARMIN/APPS/
```

동반 앱은 기존과 같습니다(`./gradlew assembleDebug` → `adb install`).

## 측정 절차

1. 폰에서 Garmin Connect가 시계와 연결돼 있는지 확인합니다.
2. 폰에서 **Camera Remote** 앱을 엽니다(알림에 `Connected: ...`가 보이면 준비 완료).
3. 폰과 시계를 실제 촬영 거리(2~3m)에 둡니다.
4. 시계에서 **CamBench**를 열고 화면을 탭하거나 START를 누릅니다.
5. 80초 동안 화면을 켜 둡니다. 화면 가운데에 움직이는 흑백 그림이 보이면 정상입니다.
6. 끝나면 요약 화면이 고정됩니다. **그 화면을 폰으로 찍어** 공유해 주세요.

추가로 하나 더 재 주세요. 기존 **CamRemote** 위젯을 열어 두고 아무것도 누르지 않은 채 몇 분 뒤에 꺼지는지 봅니다.
미리보기를 위젯에서 할지, 앱 형태로 바꿀지 정하는 데 씁니다.

## 요약 화면 읽는 법

```
size fps rtt/max draw
64x64/2b 1.4 620/900 85
...
mem peak 41/768K err+stall 0
```

| 항목 | 뜻 |
|---|---|
| fps | 시계가 1초에 실제로 그린 프레임 수 |
| rtt / max | 폰이 프레임을 보낸 뒤 시계의 수신 확인을 받기까지 걸린 평균 / 최대 시간(ms). 전송 왕복과 시계의 그리기 시간을 모두 포함하므로, 실제 화면 지연은 이 값보다 짧습니다 |
| draw | 시계가 프레임 하나를 풀어서 그리는 데 쓴 시간(ms) |
| mem peak | 측정 중 앱이 쓴 최대 메모리 / 앱 한도 |
| err+stall | 전송 실패 수 + 3초 넘게 프레임이 안 와서 다시 요청한 횟수 |

시계는 마지막 결과를 저장해 두므로, 앱을 다시 열어도 요약 화면을 볼 수 있습니다.

## 판정 기준

어느 한 크기라도 **fps 1.0 이상, rtt 평균 2000ms 이하**면 미리보기 구현으로 넘어갑니다. 넘은 크기 중 가장 큰 것을 쓰고,
없으면 "촬영 직후 정지 화면 1장"으로 범위를 줄입니다.

## 화면에 이런 문구가 뜨면

| 문구 | 원인 | 할 일 |
|---|---|---|
| `Phone app not answering` | 폰 동반 앱이 꺼져 있거나 시계와 연결이 안 됨 | 폰에서 Camera Remote 앱을 열고 다시 측정 |
| `Send error xN` | 시계에서 폰으로 보내는 메시지가 실패함 | Garmin Connect 연결 상태 확인 |
| `Waiting...` | 3초 넘게 프레임이 안 옴. 자동으로 다시 요청 중 | 계속되면 거리를 줄여 다시 측정 |

폰은 시계 응답이 5초 넘게 없으면 스스로 전송을 멈춥니다. 시계 앱을 도중에 닫아도 폰이 계속 보내지 않습니다.
