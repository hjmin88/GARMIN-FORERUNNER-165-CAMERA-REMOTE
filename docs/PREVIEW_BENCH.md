# 블루투스 사진 전송 실측

시계에서 폰 카메라 화면을 보려면 폰이 Garmin Connect 앱을 거쳐 블루투스 메시지로 이미지를 보내야 합니다.
이 경로가 얼마나 빠른지 재고, 그 결과로 기능 범위를 정했습니다.

측정 환경: Forerunner 165(펌웨어 29.05, Connect IQ 6.0.4), Galaxy S25(SM-S931N), 2026-11-13.

## 0단계: 실시간 미리보기 — 미달

폰이 가짜 흑백 프레임을 크기별로 20초씩 보내고, 시계가 받은 장수와 왕복 시간을 쟀습니다.

| 크기 | 초당 장수 | 왕복(ms) | 시계 그리기(ms) |
|---|---|---|---|
| 64×64, 4단계 | 0.1 미만 | 992 | 189 |
| 80×80, 4단계 | 수신 없음 | — | — |
| 80×80, 16단계 | 수신 없음 | — | — |
| 100×100, 16단계 | 수신 없음 | — | — |

- base64로 약 1.4KB인 메시지는 도착하고, 약 2.1KB 이상은 폰 `sendMessage` 가 `FAILURE_DURING_TRANSFER` 로 끝났습니다.
- 가장 작은 크기도 초당 1장에 못 미쳐 미리보기는 포기하고 "촬영 직후 사진 1장"으로 범위를 줄였습니다.

## 1단계: 정지 사진 1장 — 채택

| 항목 | 결과 |
|---|---|
| 화질 | 실제 사진으로 후보를 비교(`tools/still_compare.py`)해 화소 약 9,200개(세로 사진이면 83×111), 회색 16단계로 정함 |
| 압축 | 디더링 없이 행 단위 RLE(1바이트 = 회색 단계 4bit + 반복 길이 4bit). 디더링을 넣으면 점무늬 때문에 RLE가 원본보다 커짐 |
| 조각 | 메시지 하나에 원본 900바이트 이하(base64 1,200자) |
| 측정 앱 기준(카메라 앱 꺼짐) | 5조각, 탭부터 10.2~10.4초, 5회 모두 완전 수신. 조각 하나 약 2.2초 |
| 실제 사용(카메라 앱 켜짐) | 4조각, 셔터부터 약 14~19초. 조각 하나 3.9~5.3초 |

알게 된 점:

- **Garmin Connect가 전송 결과를 알려 주지 않을 때가 있습니다.** 결과를 기다렸다가 다음 조각을 보내면 거기서 멈춥니다. 그렇다고 몇 초 만에 다시 보내면, 아직 가는 중인 조각이 겹쳐 쌓여 오히려 크게 느려집니다(한 장 17~26초). 지금은 결과를 기다리되 15초가 넘으면 다음 조각으로 넘어갑니다.
- **시계 쪽 시한은 "총 시간"이 아니라 "조각이 끊긴 시간"으로 잡아야 합니다.** 카메라 앱이 켜져 있으면 조각이 느리게 오지만 꾸준히 옵니다.
- **FR165 실기기에는 `Dc.drawScaledBitmap` 이 없습니다.** SDK 시뮬레이터는 통과시키므로 실기기 로그(`GARMIN/Apps/LOGS/CIQ_LOG.YML`)로만 드러납니다. 사진은 RLE 구간을 소수 배율 사각형으로 칠해 화면을 채웁니다.
- **시계를 맥에 USB로 꽂았다 빼면** Garmin Connect 연결이 한동안 끊깁니다. 테스트 전에 Garmin Connect에서 "연결됨"을 확인하세요.

## 측정 앱 사용법

`garmin_bench/`(CamBench)는 측정 전용 시계 앱입니다. 앱 ID가 CamRemote와 달라 서로 영향이 없습니다.
시계를 탭하면 폰이 갤러리의 가장 최근 사진을 위와 같은 방식으로 보내고, 시계는 다 받기까지 걸린 시간을 최근 5회 보여 줍니다.

```bash
monkeyc -d fr165 -f garmin_bench/monkey.jungle -o garmin_bench/bin/CamBench.prg -y developer_key.der
```

- 폰에 동반 앱을 설치하고 사진 접근을 허용합니다.
- `CamBench.prg` 를 시계의 `GARMIN/APPS/` 에 복사합니다. FR165는 MTP로 연결되어 Finder에 디스크로 뜨지 않으므로 OpenMTP 같은 앱을 씁니다.
- 폰 쪽 조각별 시간은 `adb logcat -s StillSender` 로 볼 수 있습니다.

`tools/still_compare.py` 는 실제 사진을 화질 후보별로 시계 화면 모양으로 그려 비교합니다.

```bash
uv run --with pillow python tools/still_compare.py out/ photo1.jpg photo2.jpg
```
